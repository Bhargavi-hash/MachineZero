# Measured results

Files in this directory are generated by executable evaluation commands. Numbers in the main README should be copied only from these artifacts.

- `train.json` / `train.txt`: learned-model configuration and actual training losses.
- `eval.json` / `eval.txt`: learned model, random and coverage explorers, 8 held-out architectures, 320 queries per budget.
- `active_eval.json`: model-informed explorer comparison from the captured small run.
- `baselines.json` / `baselines.txt`: random-state and no-op baselines.
- `system_id_eval.json` / `system_id_eval.txt`: transparent black-box system-identification budget curves.
- `benchmark.json` / `benchmark.txt`: measured scalar and batched simulator throughput on the current machine.
- `demo.txt`: deterministic seed-2026 demo output.
- `pytest.txt`: final local test output.

CUDA throughput is left `null` when no CUDA device is available. No substitute GPU number is inserted.
